
# Athena

**A local-first AI quantitative research platform that converts natural-language financial questions into validated Python analysis and structured research reports.**

Athena combines conversational AI with deterministic quantitative models. A user can ask a question such as:

> Analyze Apple’s market risk.

Athena interprets the request, resolves the security, retrieves market data, runs statistical and tail-risk models, compares the results, and produces an explainable research report.

The language model handles **intent and explanation**. Python handles **data validation and mathematics**.

---

## Why I Built Athena

Financial analysis often requires moving between market-data platforms, Python scripts, statistical models, spreadsheets, and reporting tools.

I built Athena to explore a different workflow: describe the research goal in ordinary language and allow one system to organize and execute the analysis.

Athena is designed to be more than a finance chatbot. It acts as an AI interface to a structured quantitative research engine.

```text

          ↓
Request Parsing
          ↓
Validated QuantRequest
          ↓
Market-Data Retrieval
          ↓
Statistical Diagnostics
          ↓
Risk and Simulation Engines
          ↓
Structured RiskReport
          ↓
AI Analyst Explanation
```

### Example

```text
Analyze Apple’s risk.
```

Athena can:

1. Resolve Apple to `AAPL`
2. Retrieve historical market data
3. Calculate daily returns and statistical diagnostics
4. Measure volatility, skewness, and kurtosis
5. Test whether returns appear normally distributed
6. Run multiple Value at Risk models
7. Calculate Expected Shortfall
8. Compare results across model assumptions
9. preserve the data source and model parameters
10. Generate a structured research report with plain-language analysis

The numerical results come from deterministic Python functions—not values generated by the language model.

## What Makes Athena Technically Different

Athena separates probabilistic AI from deterministic computation.

```text
Local LLM
Understands the user’s request
        ↓
Validated analytical specification
        ↓
Python Quantitative Engine
Performs calculations
        ↓
Structured research result
        ↓
Local LLM
Explains the completed analysis
```

This architecture prevents the language model from inventing financial calculations while preserving a prevents the language model from inventing financial calculations while preserving a natural conversational interface.

Athena’s outputs can retain information such as:

- Security symbol
- Analysis period
- Market-data provider and feed
- Observation count
- Confidence level
- Model assumptions
- Distribution parameters
- Execution metadata
- Validation warnings

This makes the research easier to inspect, reproduce, and extend.

## Architecture

Athena is organized into modular layers:

### Interface

Accepts natural-language requests and presents completed research.

### Request Interpretation

Converts user intent into a structured quantitative request.

### Validation

Checks securities, date ranges, models, confidence levels, and required parameters before execution.

### Orchestration

Coordinates data retrieval, diagnostics, risk models, simulations, and reporting.

### Quantitative Engine

Executes deterministic statistical and financial calculations.

### Reporting

Transforms structured results into readable research output.

### AI Commentary

Uses a local language model to explain the completed calculations without modifying them.

## Local-First AI

Athena connects to locally hosted language models through Ollama.

Models tested in the Athena development environment include:

- Qwen 3.5 122B
- DeepSeek-R1 70B
- Custom mathematics models
- Custom programming models
- Local embedding models

Local inference provides greater control over privacy, model selection, prompts, project context, and specialized workflows.

The quantitative engine remains independent of the selected language model.

## Project Vision

Athena explores what quantitative research can become when artificial intelligence serves as the interface to rigorous computational systems.

Instead of manually configuring every stage of an analysis, a user can express the research goal directly:

```text
Compare Apple’s tail risk under multiple models.

Run a Monte Carlo simulation for this position.

Analyze how this portfolio could behave during a market crisis.

Explain which risk assumptions are driving the results.
```

Athena can identify the required workflow, execute the appropriate quantitative tools, and return a result that is both mathematically grounded and understandable.

**The goal is not to build a chatbot that talks about quantitative finance.**

**The goal is to build an AI-native quantitative research platform.**
